BIOS files (not included: they are copyrighted, use dumps of your own consoles)

  scph1001.bin        PlayStation (recommended; without it a less compatible
                      built-in replacement is used)
  gba_bios.bin        Game Boy Advance (recommended)
  gb_bios.bin         Game Boy (optional)
  gbc_bios.bin        Game Boy Color (optional)
  disksys.rom         Famicom Disk System (only for .fds games)
  syscard3.pce        PC Engine CD (only for CD games in .cue format)
  5200.rom            Atari 5200 (required)
  7800 BIOS (U).rom   Atari 7800 (optional)

Arcade BIOS zips (neogeo.zip, pgm.zip...) go with the games in roms/<system>/.
