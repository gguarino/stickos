Neo Geo
Emulator: fbalpha (these games appear in the "Arcade (FB Alpha)" list)
Put Neo Geo games here as .zip files (romsets), without unpacking them.
Romsets must match the emulator version (FB Alpha).
The Neo Geo BIOS (neogeo.zip) is required: put it in this same folder.
Saves go in roms/fbalpha/save/.
