PlayStation
Emulator: pcsx_rearmed
Put games here with extension: cue (+ its .bin files), chd, pbp, m3u, iso, img
Do not use .zip: a CD game is made of several files.
BIOS in bios/ on the SD: scph1001.bin (recommended)
Some European (PAL) games are protected by LibCrypt: they need a .sbi file
with the same name as the game (e.g. "Radikal Bikers.sbi" next to
"Radikal Bikers.chd"), otherwise they freeze after a few seconds.
